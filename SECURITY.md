# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues.

This repository only bundles the skills from [gws-skills](https://github.com/m0ch1m0ch1/gws-skills) and [openshift-skills](https://github.com/m0ch1m0ch1/openshift-skills). Report vulnerabilities in a skill privately using **Report a vulnerability** on the **Security** tab of the repository that contains the skill.
